# Portfolio-ATS-Resume-Builder
Portfolio + ATS Resume Builder: A Browser-Based Tool for Generating Multi-Design Portfolio Websites and Scored, ATS-Optimized Resumes

A browser-based builder that generates 10 distinctly designed portfolio websites and a coached, ATS-safe resume (DOCX/PDF/TXT) from a single data entry. Runs entirely client-side with React + Vite — no server, no account, no data leaves your machine.
